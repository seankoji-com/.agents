# agent-tuneup planning criteria

Every requirement needs evidence distinguishing parse, provider load and live enforcement.
Challenge scope precedence, effective access, confidential recipients, unsupported
capabilities and no-change conclusions. Proposals must cover every changed key,
backup/conflict behavior, rollback, denied writes and a minimal verification.
Bootstrap recommendations must justify launch/setup commands and coverage.
Never equate equal risk counts with safe access or approve a settings write.

Follow the installed shared reviewer standard. Cover every requirement and
load-bearing decision with outcomes, source evidence, counterexamples, simpler
alternatives and limits. Retain every prior objection and disposition. Empty
findings are valid with complete coverage. Review grants no execution authority.
