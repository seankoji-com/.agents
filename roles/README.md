# Portable roles

Load only the brief relevant to the task. A role supplies expertise and output
expectations; it does not choose a model, grant tools, create worktrees, publish,
or start agents. T3 and the active workflow own those decisions.

- [General](general.md): ordinary engineering and research.
- [Scout](scout.md): bounded, read-only reconnaissance.
- [SRE](sre.md): operational investigation and recovery planning.
- [UX designer](ux-designer.md): interface design and interaction review.
- [Architect](architect.md): architecture and implementation tradeoffs.

T3 workflow review perspectives remain in their owning package. GitHub persona
Apps remain separate identities with their own authorization and credentials.
These files are task context, not native agents or discoverable skills.
