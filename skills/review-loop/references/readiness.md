# Readiness rounds for think

Use the decision brief as the candidate. The acceptance gate is whether any
unresolved issue could materially change the next implementation step. Use a
reasoned readiness verdict and an attempt record.

1. On setup record the user's request, frozen brief, settled decisions,
   assumptions, next step and every material brief author's model family.
2. Before quota ranking on every dispatch, exclude each material brief author's
   family. Require a separate read-only reviewer. If an author identity is
   unknown or no eligible authorised route is available, return incomplete
   with the specific reason.
3. Ask whether the gate is met. Require reasoning for the verdict and, for
   every material gap, its impact and the question or investigation that
   could resolve it. Confirm the report covers the current brief.
4. Verify gaps, investigate answerable facts, and return decisions that need
   the user to `think`. Resume on the same record. Revise the brief and
   recheck changes that affect the gate.
5. Allow a total of three attempts across the interview and all resumes. Each
   failed dispatch, review or retry consumes an attempt. If readiness remains
   unverified, apply [budget diagnosis](../../review/references/budget-exhaustion.md)
   within the same allowance. Return `ready` or `incomplete`, the current brief,
   remaining gaps and the next action. Implementation requires verified
   readiness.
