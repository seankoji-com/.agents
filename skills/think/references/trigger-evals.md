# Trigger evals: think

Prompts for the manual trigger check described in the new-skill skill.
Run each in a fresh session; record which skill fires.

## Should fire

1. Let's think this through.
2. Think about whether we need a cache here.
3. Interview me about this feature until it's ready to build.
4. Stress-test this plan and turn it into a brief.
5. Keep thinking about the migration approach.

## Should not fire

1. Are you sure? (expect: challenge)
2. Review this plan for gaps. (expect: review)
3. Compare two UI directions for the dashboard. (expect: choose-design)
4. What's the capital of France? (expect: none)
5. Clear the backlog. (expect: backlog-burn)
