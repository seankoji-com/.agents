# Trigger evals: settle

Prompts for the manual trigger check described in the new-skill skill.
Run each in a fresh session; record which skill fires.

## Should fire

1. /settle
2. We're done here; close out the thread.
3. Wrap up this thread now that the PR has merged.
4. Settle this thread.
5. Finish up: everything's handed back.

## Should not fire

1. Save this decision to memory. (expect: reremember)
2. Merge the PR. (expect: babysitter)
3. Delete old local branches. (expect: none)
4. Ship it. (expect: ship)
5. Clear the backlog. (expect: backlog-burn)
