# Trigger evals: challenge

Prompts for the manual trigger check described in the new-skill skill.
Run each in a fresh session; record which skill fires.

## Should fire

1. Are you sure about that?
2. Challenge the assumptions in this migration plan.
3. Get me a second opinion on this architecture.
4. Pressure-test this pricing idea.
5. Poke holes in my proposal before I send it.

## Should not fire

1. Review this PR for bugs. (expect: review)
2. Think this feature through with me and write a brief. (expect: think)
3. Compare three layout options for the settings page. (expect: choose-design)
4. Fix the typo in the README. (expect: none)
5. Iterate with independent review until it scores 9. (expect: review-loop)
