From install to first run in a minute

A skill is a short guide your agent reads when it does a particular kind of work. Nothing runs in the background and there is no account to make.

  1. Install a skill

    From your project folder, run npx skills add seankoji-com/.agents --skill think. The installer asks which agents to add it to. It needs Node.js 22.20 or later.

  2. Ask for the job

    Name the skill in a normal request, such as Use think on this plan before we build it, or use a slash command like /think where your agent supports them.

  3. Get the result and its evidence

    Your agent follows the skill's steps and tells you what it decided, what it checked and what still needs you.

Every skill in the library

Copy a command to install one skill, or tick the ones you like and copy a single command for all of them. Each name opens the exact instructions your agent will follow.

What you need

A coding agent

The skills are written for T3 Code and Codex. Claude Code and other agents that support skills can use any skill whose tools they provide. A skill marked "Needs T3 Code" relies on T3's background workers.

Node.js for the installer

The Skills CLI needs Node.js 22.20 or later. The skills themselves are Markdown, plus a few small Python 3.10 helpers.

Your say on what happens

Skills that commit, push or merge stay inside what you asked for. "Review it but don't merge" is a limit the agent keeps.

Install everything and choose in the terminal: npx skills add seankoji-com/.agents
