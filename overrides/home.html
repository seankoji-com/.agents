Install on macOS or Linux

The stable formula is still v0.4.0, from before ralph. Until the next release, install the HEAD build:

brew install --HEAD seankoji-com/tap/t3-plugins
t3-plugins setup
t3-plugins doctor

Then turn on Show skills in slash menu in T3, restart the agent session, and send $t3-imps doctor in a thread.
